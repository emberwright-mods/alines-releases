# Emberwright Architect Lines: releases

Downloads of **Emberwright Architect Lines** (Alines), a building mod for Enshrouded: lines, surfaces, volumes and stacks of blocks with a 3D preview, undo and redo, in solo and multiplayer.

This repository only holds the release files. The installer and the update feed read it; players don't need to come here.

- **Status:** beta in preparation, nothing published yet.
- A release pairs **ShroudForge AL Edition** (the official [ShroudForge](https://github.com/bonsaibauer/shroudforge) by Bonsaibauer, plus pull requests not merged yet) with Architect Lines, tested together.
- The Emberwright website, with the download page and the install guide, is coming.
